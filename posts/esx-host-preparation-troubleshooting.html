Host preparation fails for more reasons than connectivity. This day went through the usual suspects.

Goals

  • Troubleshoot ESX preparation failures

What I covered

  • Insufficient RAM or storage on the host.
  • Incompatible versions.
  • Stale NSX configuration left on the host.
  • Known bugs.
  • Host-to-manager communication failures.

Lessons learned

  • Start from the stage that failed instead of treating every failure as a connectivity problem.
  • Force Remove clears the transport node from the NSX inventory but doesn't reset the host. Remove stale configuration before preparing it again.
  • Check the VMware Interoperability Matrix before deploying.
