A fundamentals lab, but it touches almost every part of vCenter. A good way to refresh the basics in one sitting.

What I did

VMs

  • Provisioned a Photon OS VM, turned it into a template and deployed a new VM from it.
  • Created tags and assigned them to VMs.
  • Migrated VMs between hosts in the same cluster.

Cluster

  • Enabled vSphere HA and fully automated DRS on a cluster.
  • Added a host to the cluster and mounted a datastore on it.

Alarms with actions

  • Host CPU above 90% for 5 minutes: put the host into maintenance mode.
  • VM CPU ready above 8000 ms for 5 minutes: shut down the guest.

Networking, security and storage

  • Created a standard switch, enabled vDS health checks and added a port group.
  • Created a new vDS and migrated VMs to it from the standard switch.
  • Enabled lockdown mode, both normal and strict.
  • Added, edited and removed an SSO role, and created a user and a group.
  • Created NFS 3 and VMFS 6 datastores.
