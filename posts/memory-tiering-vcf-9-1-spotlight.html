A shorter version of the What's New: Compute on VCF 9.1 lab that zooms in on memory tiering.

What I did

  • Configured memory tiering as a draft, with a tier device and a mirror device.
  • Set per-VM advanced parameters.
  • Compared VCF Operations dashboards with tiering enabled and disabled.
  • Removed the configuration in the UI, then enabled it again at host level from the CLI.

Advanced parameters

sched.mem.EncryptTierNVMe = TRUE    # encrypt the NVMe tier for this VM
sched.mem.enableTiering   = FALSE   # turn memory tiering off for this VM

tier_size_pct sets the DRAM-to-NVMe ratio.

Before using the CLIPut the host into maintenance mode before configuring memory tiering from the command line.
