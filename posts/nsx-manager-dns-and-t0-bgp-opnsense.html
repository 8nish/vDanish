A mixed day: DNS for NSX Manager, a first attempt at bringing a vSphere 8 environment into VCF 9, and BGP between a Tier-0 and an OPNsense firewall.

Goals

  • Configure NSX Manager DNS entries on the DNS server
  • Move a vSphere 8 environment to VCF 9.0 (not achieved yet)
  • Configure BGP between the Tier-0 and an OPNsense firewall

What I covered

  • Troubleshoot connectivity from the Tier-0 SR VRF on the edge, not from the edge management interface.
  • On OPNsense, check the routes before worrying about the rules.
  • Make sure the DVS port group uplink to OPNsense is trunked.
  • Keep troubleshooting structured, and think like a router when configuring one.

Lessons learned

  • Importing the vCenter environment needs a three-node NSX Manager cluster.
  • NSX 4.2.4.1.0 (build 25554964) is the version to use with vCenter 8.
  • 73 validations have to pass before the vCenter environment can be imported.
