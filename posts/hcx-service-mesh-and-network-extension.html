Second HCX day: building the service mesh, stretching networks so VMs keep their IPs, and routing locally with MON.

Goals

  • Explain how network and compute profiles define appliance networking, services and placement
  • Create and validate a service mesh between paired sites
  • Choose Network Extension topologies that keep VM IP addresses
  • Configure Mobility Optimized Networking and troubleshoot failures

What I covered

  • The setup order: network profiles, then compute profiles, then the service mesh.
  • One service mesh versus separate meshes for migration and Network Extension.
  • Creating a Network Extension, the NSX segment configuration and activation checks.
  • Troubleshooting transport zones, IP pools, tunnels, MTU, bandwidth and gateways.

Lessons learned

  • Size the appliance IP pools before deploying. Every enabled appliance needs an address.
  • Split services or add appliance pairs when bandwidth, stretched-network limits or availability call for it.
  • Check tunnels, topology, diagnostics and extension status before migrating anything.
  • With MON, enable the destination Tier-1 and use policy-based routing for traffic that must still go through the source.
