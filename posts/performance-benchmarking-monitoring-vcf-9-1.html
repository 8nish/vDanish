This lab is about reading performance: where to look in VCF Operations, how to correlate cluster metrics and what esxtop is telling you.

What I did

  • Viewed cluster performance metrics and constraints in VCF Operations.
  • Correlated CPU capacity usage and contention, memory contention and demand, and workload.
  • Used the storage overview dashboard and previewed the real-time metrics UI.
  • Monitored hosts with esxtop.
  • Looked at VMmark for performance benchmarking.

esxtop cheat sheet

ColumnMeaning
ID / GIDProcess ID / group ID
NAMEWorld or group name
NWLDNumber of worlds in the group
%USEDPhysical CPU core cycles used
%RUNShare of scheduled time the world ran
%SYSTime on interrupts and system work; high values point to heavy I/O
%WAITTime blocked or busy-waiting
%VMWAITVM time blocked waiting for events
%RDYReady to run but queued for a CPU
%IDLEVM idle time
