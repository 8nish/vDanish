Lab topology

Module 1: NSX Federation fundamentals

Reading only. The short version:

  • Global Manager (GM): config for all locations, active in one site, standby in the other.
  • Local Manager (LM): one per site. GM config wins over local config.
  • RTEPs: carry overlay traffic between sites, separate from the normal TEPs.
  • Stretched Tier-0: primary site handles north-south, secondary takes over if it fails.

Key takeaways

  • Copy the API cert thumbprint before onboarding a site.
  • RTEPs need their own VLAN and a WAN that carries 1700 MTU.
  • Primary/secondary Tier-0 plus an AS path prepend on the secondary keeps traffic symmetric.
  • Neighbor local AS lets one Tier-0 show a different AS to different peers.
